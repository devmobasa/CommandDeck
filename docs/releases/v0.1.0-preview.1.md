The first public preview of **CommandDeck**, a keyboard-first command palette
and launcher for **Omarchy and Hyprland**. Press **Ctrl+Space**, type, and act.

> [!NOTE]
> This is a preview. Expect rough edges, and please
> [report problems](https://github.com/devmobasa/CommandDeck/issues). The
> extension SDK and the standalone Hyprland host are experimental.

## What's in this release

### One search for the desktop

- Find apps, files and file text, Hyprland config keys, windows and workspaces,
  Omarchy menu actions, user services and timers, your processes, desktop
  controls, projects, snippets, quicklinks, time zones, emoji, and web search.
  PDF and document text is searched when `pdftotext` or `pandoc` is installed
  and you turn it on.
- A prefix limits the search to one source: `app:`, `file:`, `text:`, `cfg:`,
  `oma:`, `win:`, `ws:`, `herdr:`, `htab:`, `clip:`, `snip:`, `proj:`, `ctl:`,
  `kill:`, `svc:`, `link:`, `web:`, `tz:`, `emoji:`, `ai:`, `hey:`, `browse:`,
  and `script:`. Combine and exclude them, for example
  `file: app: roadmap -workspaces:`. Press `?` to see them all.
- Top Matches come first, then results grouped by source. Ranking learns from
  what you open, on your computer only, and you can turn that off. Mark
  favorites, give results aliases, hide results, save searches with their own
  shortcut, and add filter aliases. **Why this result?** explains the order.

### Made for Omarchy and Hyprland

- The launcher uses the colors of the active Omarchy theme.
- `oma:` searches Omarchy's whole menu. Submenus open in place, and toggles show
  their current state.
- Hyprland and Omarchy config keys open in your editor at their file and line.
  Choose a graphical or a terminal editor in Settings.
- Windows and workspaces are searchable, with optional previews.
- [Herdr](https://github.com/herdrdev/herdr): `herdr:` finds spaces and tabs,
  `htab:` finds tabs and shows which agent tabs need attention, and Enter jumps
  there.

### Calculator

- Type `100 * 5`, `100 km to miles`, `100 usd to eur` (daily ECB rates), or
  `days until 11 sep`. The result appears as you type, without a prefix.
- Start with `=` for the full calculator. Enter copies the result.

### Do things, not only open them

- `>` runs any program without a shell, for example `> htop`.
- **Ctrl+K** shows the actions for a result. **Ctrl+1** to **Ctrl+9** run a
  numbered result.
- Desktop controls: volume, media keys, Wi-Fi, Bluetooth, the color picker, and
  window placement such as `left half` (`ctl:`).
- `kill:` lists your processes, largest first. Terminate or force kill one after
  you confirm.
- `svc:` lists your user services and timers: show the status and recent logs,
  start, stop, or restart a unit after you confirm, or edit it.
- Snippets and templates with named inputs, script commands from
  `*.commanddeck.json` manifests with their output shown in the launcher,
  `browse:` for folder navigation, and `commanddeck pick`, a picker for your own
  scripts.
- Clipboard history, off until you turn it on: text, links, images, and files,
  with pins and keywords.
- HEY mail search and triage with `hey:`, when the HEY command line tool is
  installed.

### Optional AI, off until you turn it on

- **Direct providers:** Ollama or any OpenAI-compatible endpoint. Before anything
  is sent, CommandDeck shows the exact request and asks you to confirm it.
- **Embedded assistant:** `ai:`, `codex:`, `claude:`, `cursor:`, or `grok:` talks
  to your local Codex, Claude Code, Cursor, or Grok command line tool inside the
  launcher. The daemon enforces the trust level that you choose, and tools run
  only after you confirm them.
- Prompt templates, and an optional package helper, installed separately, for
  pacman changes with an exact preview and Polkit authorization.

### Settings

- **Ctrl+,** opens Settings inside the launcher, with six pages that you can
  search: Search, AI, Editors, Filters, Shortcuts, and Customization.
- Display size, panel width and height, compact layout, the preview pane,
  transparency, favorites, and source order apply at once.

### Extensions (experimental)

- C# extensions run as separate processes in a Bubblewrap sandbox, with the
  permissions that you grant. The SDK and a test kit are included, and
  `commanddeck extensions` manages local packages.

### Command line

- `commanddeck search`, `suggest`, `status`, `doctor`, `reindex`, `index`,
  `catalog`, `preferences`, `quicklinks`, `saved-search`, `filters`, `hotkey`,
  `ai`, and `pick`. `commanddeck --help` lists every command.

### Private and fast

- No telemetry. AI, clipboard history, search history, and extensions stay off
  until you turn them on. Everything is stored on your computer.
- A Native AOT C# daemon keeps an SQLite FTS5 index. In our measurements, the
  window opens in about 25 ms (median, from the shortcut to the visible window).
- `commanddeck doctor` checks the installation, the hotkey, and the index.

## Requirements

- Omarchy with shell plugins on Hyprland, a systemd user session, `jq`, `icu`,
  and glibc 2.39 or later.
- Builds for `linux-x64` and `linux-arm64`. This is the first `linux-arm64`
  build: it is built and smoke-tested in CI, but it has not run on ARM hardware
  yet, so please report what you find.

## Known issues

- The assistant's answer can appear in the launcher a few seconds after the
  assistant has finished, and the footer can keep showing "Asking Codex…"
  afterwards.
